# Privacy policy

Galactic Library stores its library database locally in the current Chrome profile. It has no developer-operated server, analytics, advertising, affiliate links, account system, or cloud synchronization. When the user explicitly selects **Find Open Library metadata** for one local book, Galactic Library sends only that title and its available author name to Open Library's public search endpoint. It displays candidate works and stores the selected metadata locally only after the user selects **Apply**; it does not bulk-enrich a provider library.

The Steam importer reads game and DLC IDs, titles, and DLC parent App IDs only after the user selects **Sync Steam library** on Steam Store while signed in. It reads the account's owned App IDs, then sends those IDs to Steam's own StoreBrowse title service to resolve entries Steam identifies as games or DLC. The GOG importer reads game IDs, titles, and platform support only after the user selects **Sync GOG library** on GOG while signed in. It reads GOG's paginated owned-games library, including hidden games when GOG reports them. The Epic importer reads game and add-on IDs, titles, platforms, and add-on parent IDs only after the user selects **Sync Epic library** on Epic Games Store while signed in. It reads the signed-in Epic library and excludes Unreal Engine assets, private/test entries, and items Epic does not identify as games or add-ons. The Audible importer reads audiobook IDs, titles, a sanitized Audible title-page URL, and any displayed author, narrator, and series metadata only after the user selects **Sync Audible library** on Audible while signed in. It makes same-site requests to paginate the Audible Library and records a title as subscription-linked only when its card explicitly offers removing it from the library; other Audible entries remain unknown. The Kindle importer reads book and personal-document IDs, titles, available authors, series, collections, acquisition dates, entitlement sources, and available publisher, publication-date, and format fields only after the user selects **Sync Kindle library** on Amazon while signed in. It makes same-site requests to the Amazon Content & Devices Books and Personal Documents libraries and does not bulk-request individual product pages. Kindle purchases are stored as owned; Kindle Unlimited, Prime, rental, and trial titles are stored as subscription records; personal documents are stored with an unknown ownership state. The Amazon Video importer reads movie and TV title IDs, titles, card types, sanitized detail-page URLs, available artwork URLs, and explicit purchase or rental labels only after the user selects **Sync Amazon Video library** on Amazon's signed-in Purchases & Rentals page. It reads only rendered title cards from that view and scrolls the page to load additional cards; it does not import Watchlist or Prime-included titles and does not request individual detail pages. Explicit purchase cards are stored as owned, explicit rental cards are stored as rentals, and ambiguous cards remain unknown. The Fandango at Home importer reads available content IDs, titles, card types, sanitized detail-page URLs, artwork URLs, and explicit rental labels only after the user selects **Sync Fandango at Home library** in Fandango's signed-in My Library view. It requests only Fandango's same-site My Movies and My TV Shows **View All** grids that are visibly linked from that page, falling back to rendered-carousel traversal only when those links are unavailable; it does not import free browsing results or request individual detail pages. Explicit rental cards are stored as rentals; other library cards are stored as owned. The Kobo importer reads title IDs, titles, available author and series labels, sanitized detail-page URLs, cover URLs, and format only after the user selects **Sync Kobo library** on Kobo's signed-in My Books page. It reads rendered cards and follows visible pagination; it does not emulate a Kobo device, use a device API, request individual product pages, or ask for, copy, or store a Kobo password, cookie, or token. The Humble importer reads purchase identifiers, bundle names, purchase dates when Humble provides them, and supported book/comic, audiobook, and game entitlement metadata only after the user selects **Sync Humble purchases** on Humble's signed-in Purchases page. It redacts third-party redemption-key values from each purchase-detail response before parsing it, so those values are never stored, exported, or logged. None of the importers asks for, copies, or stores a provider password, cookie, OAuth/Web API token, device authorization, or redemption-key value. Future provider importers will follow the same signed-in, user-initiated model. Backups are created only when the user explicitly selects Export and are restored only when the user explicitly selects a file.

Stored data will include provider item identifiers, titles, ownership state, provider metadata necessary for the library, sync timestamps, user match decisions, and any extension IDs the user explicitly allows as companion clients. Galactic Library requests Chrome's `unlimitedStorage` permission because a complete multi-provider library, particularly a long Humble purchase history with local purchase provenance, can exceed Chrome's normal 10 MB local-storage quota. The permission only increases the amount of data this extension may keep in the local browser profile; it does not send data off-device or provide access to other sites.

If the user explicitly allows a companion extension such as Humble Comic Library, Galactic Library accepts only that extension ID's `PING`, aggregate status, and batched exact-title match requests. It returns only the requested title's matching provider, provider item ID, title, and ownership state; it never exposes the full library or any credential. This exchange occurs locally between extensions in the same browser and does not use a remote server. Removing the local library also removes the allowed companion-extension IDs. Data otherwise remains until the user clears it, restores another backup, or uninstalls the extension.
