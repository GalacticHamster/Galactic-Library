# Appearance

In **Settings → Appearance**, choose **Dark**, **Light** or **System**. System follows your browser/operating-system colors and updates when they change. The choice is remembered in this browser across workspaces and reopening GL. It is outside your library backup.

Dark retains GL's navy surfaces, light text and purple actions. Light uses neutral backgrounds, white cards, dark text and the same purple actions. Green Owned, blue New, orange Possible and purple Partial keep their existing meanings.

HB and FAN offer the same choices in their settings. **Follow Galactic Library appearance** uses their existing GL link. While following, GL controls the mode and the local selector is disabled. Open another page or select **Refresh linked appearance** after changing GL's appearance. If GL is unavailable, the last linked mode is retained; without one, your independent local choice is used. Disable following to use that independent choice again.

New installations default to System. Existing installations without an explicit appearance choice retain GL Dark or companion Light. Appearance affects extension panels and overlays, not native website purchase controls or your library data.
