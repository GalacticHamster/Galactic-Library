### B1 repair checkpoint and live retest

The repair selects the common cards' vertical scrolling ancestor, visits overlapping viewports rather than skipping virtualized middle groups, and limits continuation controls to the common main content region when identifiable. Visible ancestor busy indicators and outside pagers explicitly associated through `aria-controls` still block completion; hidden/disabled controls do not. With no identifiable main region, checks conservatively retain page scope. Card changes, scroll-range changes, library loading and real Load more controls reset the existing three-poll quiet period. The 250-pass cap, unreadable-card rejection, reported-count validation and full-snapshot writer gate remain. A bare quiet period cannot prove completeness for an unknown layout that silently delays content without a loading signal; live terminal validation is still required.

Validation entry points: `node tests/browser.js --release --amazon-video` and the same command with `--firefox`. Each currently passes 29 synthetic packaged-browser checks, including real production-panel/writer preservation on failure. These use disposable profiles and local fixtures, not authenticated Amazon sessions. Existing packaged importer suites also passed 105 checks per browser.

Live retest (repeat separately in Chrome and Firefox):

1. Export a backup first. Reload the updated extension, then open Amazon Video **My Stuff → Purchases & Rentals**, with no search/filter restriction, and let titles appear.
2. Click GL **Full rescan**. Record the exact completion message, movie/TV totals and browser/build. Check representative first, middle and last titles against the website, including any rental/purchase distinctions. Do not assume the count equals purchases: TV titles and seasons are separate source products.
3. Repeat unchanged and confirm the same membership/access results; try **Quick update** afterward. Confirm other provider libraries and manual corrections remain intact.
4. If a scan fails, click its newly available **Export scan diagnostics** button and provide `GL-amazon-video-scan.json` plus the exact error. It contains only numeric scroll/control checks and fixed reason codes, with no titles, product IDs, URLs, credentials or account identifiers. A failure sends no replacement snapshot. The export action is hidden on successful scans; no DevTools or saved authenticated page is needed.

Do not mark B1 complete until live results establish the terminal behavior, or the remaining defect is diagnosed and separately addressed.
